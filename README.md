# memm

engineering memes.

memm is a meme editor for picking a template, writing a caption, and exporting the finished png.

## features

- hand-picked, searchable templates
- canvas typography controls for weight, stroke, shadow, and alignment
- png exports at the template's native resolution
- no account. no watermark.

## stack

- react 19
- tanstack start and tanstack router
- vite
- bun
- tailwind css
- motion for interface animation

## run locally

```sh
bun install
bun run dev
```

build for production:

```sh
bun run build
```
