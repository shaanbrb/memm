# memm — Complete Product Redesign





You are designing **memm** completely from scratch.





Do **not** use the existing implementation as a design reference.





The only thing that should remain is the core functionality:





* Browse meme templates


* Create memes


* Upload custom templates


* Edit memes


* Download memes


* Share memes





Everything else should be reimagined from first principles.





The final result should not resemble a typical meme generator.





It should feel like a premium creative application built for internet culture.

↓

↓
